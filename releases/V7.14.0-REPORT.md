## Architecture retenue

- **Un seul moteur Google** mutualisé (`lib/google/*`) pour WordPress et Webflow.
- Configuration **par espace** via `GooglePropertySelection` + `WorkspaceCmsSettings.gscPublicSiteUrl`.
- Identité OAuth Google **commune** (compte de service / OAuth existant) ; propriété GSC **jamais auto-copiée** d’un espace à l’autre.
- Webflow : **Search Console uniquement** (GA4 hors périmètre V7.14.0).
- Isolation stricte : `workspaceId` figé au lancement de sync ; propriété unique par espace ; agrégations / métriques / opportunités scopées.

## Rapprochement des URLs Webflow

- Inventaire `WebflowCmsItem` : `isLive` + `status=published` + `isConfirmedPublicUrl`.
- Refus Designer / preview / admin.
- Pas d’URL construite depuis le slug seul ; brouillons → message explicite Performances.

## Synchronisation

- `startGoogleSync(mode, workspaceId)` + figement propriété / workspace.
- Pagination Search Analytics `rowLimit` 25 000 + `startRow`.
- Idempotence upserts ; sync concurrente refusée **par espace**.
- Cron : itère les espaces ayant une propriété GSC/GA4.
- Échec : données antérieures conservées.

- Panel : état brouillon explicite ; fetch métriques seulement si URL publiée vérifiée.

## Opportunités SEO

- Sans GSC : comportement V7.12.2 (analyse éditoriale seule) préservé.

- `googleDataAvailable` reflète la présence réelle de stats pour la propriété de l’espace.
