## Architecture retenue

- Réutilisation du **moteur GA4 existant** (`lib/google/ga4-sync.ts`) mutualisé WordPress / Webflow.
- Configuration **par espace** via `GooglePropertySelection` (GSC et GA4 **indépendants**).
- OAuth commun (`analytics.readonly` + `webmasters.readonly` déjà présents).
- Isolation hostname via Admin API (flux web) + filtre Data API `hostName`.
- Webflow **non configuré par défaut** pour GA4 ; WordPress GA4 `399634894` préservé.

Modes supportés par espace : aucun / GSC seul / GA4 seul / GSC+GA4.

## Configuration par workspace

- Sélection GA4 : `ga4AccountId` / `ga4PropertyId` / `ga4PropertyName`.
- Domaine public : `gscPublicSiteUrl` / `siteUrl` (partagé avec GSC).
- Refus si propriété déjà liée à un autre espace.
- Refus si aucun flux web ne correspond au domaine public.
- Measurement ID `G-…` **non** utilisé pour la Data API (ID numérique uniquement).
