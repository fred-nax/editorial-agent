## 4. Performance mesurée (couche Prisma, pas app entière)

Voir `docs/audits/PERFORMANCE_BENCHMARK_V7.16.2.md`.

| Mesure | Valeur |
|--------|--------|
| Volume | **4200** générations WP synthétiques (bench isolé) |
| Avant | ~**37 ms** `findMany` sans select (liste complète) |
| Après | ~**3,3 ms** page de **20** (`count` + `findMany` borné) |
| Variation | ≈ **−91 %** sur **cette requête d’historique uniquement** |
| Exécutions | multi-runs cold/hot (1000 puis 5000) ; reconfirm 2026-11-27 |

**Ne pas** généraliser ce −91 % à l’ensemble de l’application.
