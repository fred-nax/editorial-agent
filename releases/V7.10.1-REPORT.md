## 2. Modifications principales

### Connecteur Webflow
- `lib/webflow/client.ts` — GET + POST `/collections/{id}/items` uniquement ; interdit live/publish/PATCH/PUT/DELETE ; impose `isDraft: true`, `isArchived: false`.
- `lib/webflow/drafts.ts` — `buildWebflowFieldData` (slugs dynamiques), anti-doublon par slug, création brouillon, lecture `itemId`.
- `lib/webflow/content-validation.ts` — HTML Rich Text (H1, scripts, styles, H2/H3, slug/titre).
- `lib/webflow/reading-time.ts` — estimation locale si mapping `reading_time` présent.
- `lib/webflow/readiness.ts` — gate génération (token, site, collection, mapping, agent).
- `lib/cms/webflow-connector.ts` — `createDraft` opérationnel (brouillon seul).

### Agent
- Registre : outils Webflow = `web_search` + `create_webflow_draft` uniquement.
- `lib/agent/webflow-draft-tool.ts` branché dans `run-session.ts`.
- Isolation stricte : pas de `create_wordpress_draft` ni fallback WordPress sur destination Webflow.

### UI / API
- Destination Webflow sélectionnable si readiness OK (`/api/cms/destinations` → `selectable`).
- `/articles/new` : picker + image à la une désactivée pour Webflow.
- `/api/generate` : vérifie readiness + refuse featured image Webflow.
- Progression / détail : `creating_webflow`, `cmsDestination`, `cmsExternalId` ; pas de `wpPostId` / `wpUrl` inventés.

### Hors périmètre (volontaire)
- Images, catégories, auteurs CMS (pas de références inventées).
- Publication / live / suppression distante.
- MCP, déploiement VPS, migrations destructives.
- Inventaire WordPress pour maillage Webflow.

## 5. Correctif prompt / progression (post 1er test manuel)

**Cause du 1er échec** (`sess_0d19b928…`, 72283 ms) : le prompt dynamique demandait encore `create_wordpress_draft`. L’agent Webflow a fait `web_search` + rédaction (`output_text`) puis `turn.completed` sans `function_call`.

**Correctifs :**
- Prompt Webflow dédié exigeant `create_webflow_draft` (prompt WP historique inchangé).
- Journalisation des outils de session ; aperçu texte agent en diagnostic uniquement (pas de création auto).
- Progression : conserve l’étape métier à l’échec (écriture/recherche) au lieu d’afficher « Préparation ».
- Tests : `tests/webflow-prompt-tools-v7101.test.ts`.

## 6. Limites V7.10.1

- Pas d’image / catégorie / auteur Webflow.
- Pas d’URL d’édition Webflow fabriquée.
- Pas de maillage interne basé sur l’inventaire WP.
- Actions WP (featured image, SEO plugins, catégories) désactivées / absentes pour Webflow.
- Lecture temps de lecture locale seulement si mapping présent.
- Reprise : si création ambiguë, pas de relance auto — contrôle slug préalable.
